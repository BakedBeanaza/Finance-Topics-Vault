# Excel Ribbon-key Shortcuts
`Alt (Tap)` + `H` + `O` + `I` - Adjust Cell Size according to content (Width)

`Alt (Tap)` + `W` + `V` + `G` - Cleaner Look (Remove Gridlines)

`Alt (Tap)` + `H` + `V` + `V` - Pasting

`Ctrl (Hold)` + `R` - Fill Right Command

`Alt (Tap` + `H` + `K` - Accounting/Financial Format 
- Applicable to numbers only, 
- adds comma \[number separation], 
- adds decimals \[2 places])

`Alt (Tap)` + `H` + `9` - Remove Decimals; do this shortcut twice since 

`Alt (Tap)` + `H` + `A` + `L, C, R` - Align content:
- if `L` - align content to the left
- if `C` - align content on the center
- if `R` - align content on the right

`F2 Key (Tap)` - current selected cell becomes active (editable)
- if you selected multiple cells, the leftmost cell first becomes active
-  to prompt a single cell active amongst a range of selected cell, press `Enter`

`Ctrl (Hold)` + `PgUp, PgDown` 
- Move Between sheets
- `Ctrl (Hold)` + `PgUp` - move to the left sheet
- `Ctrl (Hold)` + `PgDown` - move to the right sheet

`Alt (Hold)` + `Equals Sign (=)`
- shortcut for the `=SUM()` formula
- it prompts a selectable cell that you can resize using the `SHIFT` key
# Parenthesized negative numbers
- With the usual formatting utilized in your machine (Laptop or PC), if you were to make a value negative, it would appear as a number with a 'minus sign'. 
	- `-100,000`
- However in Accounting and Finance, we usually prefer displaying negative numbers in a parenthesized manner
	- `(100,000)`
- This portion will teach you how to set up your machine to display **parenthesized negative numbers**

in the Task Search Bar, Search "**Control Panel**"
![[Pasted image 20260731220354.png]]

Open that and navigate to "**Clock and Region**", directly click the "**Change date, time, or number formats**"
![[Pasted image 20260731220522.png]]

As a result, this will pop-up
![[Pasted image 20260731220601.png]]

Click "**Additional Settings**" which is located by the **lower-right** of that mini-window, of which this will appear
![[Pasted image 20260731220701.png]]

Navigate to "**Currency**" which is located by the **upper-left** corner besides "**Numbers**"
![[Pasted image 20260731220823.png]]

Click the **drop-down bar** on the "**Negative currency format**" and select this "**blue-highlighted option**"
![[Pasted image 20260731220917.png]]

Afterwards, click "**Apply**" then "**OK**" twice.
![[Pasted image 20260731221014.png]]

After such adjustments are done, the numbers in your excel file won't automatically transform.
You have to:
- restart your computer,
- re-input your numbers and so on.
